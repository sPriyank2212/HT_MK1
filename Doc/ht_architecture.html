Overview

Bus / net legend

analog sense (low-V) high voltage (≤500 V) SPI I²C control / GPIO

Continuity and resistance share the current path (HI_COM → mux → harness) but sense differently: continuity reads the pulled-up node at U4; precision resistance reads each line's V_HI and V_LO on the ADS124S08 array and takes the difference (Kelvin), so the mux Rₒₙ cancels. HV is a separate isolated 500 V path.

Precision resistance — Kelvin outputs
True wire RThe value you want: L × Ω/m.
ΔV sensedI × R_wire — the ADS124S08 differential reading V_HI − V_LO across the wire only. Mux Rₒₙ and the 100 Ω return are outside the sensed nodes, so they don't appear here.
Injection path / V needed2·Rₒₙ + 100 Ω + wire, and I × that. The current still flows through the muxes; if I × path > 3.3 V it clamps and I is no longer the programmed value.
Actual inject currentIf clamped, 3.3 V ÷ injection-path — lower the current (≈1 mA) or mux Rₒₙ so it matches the programmed I.
ADS LSBVref ÷ 2²⁴ ÷ PGA gain — the 24-bit step (≈149 nV at gain 1, Vref 2.5 V).
Resolution RLSB ÷ I — the smallest resolvable wire resistance. With Kelvin removing the offset, this is the real floor (µΩ-scale), not the mux drift.
