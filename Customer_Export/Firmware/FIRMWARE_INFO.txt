Change in this build (since the 2026-11-13 image)
  - FIX: the independent watchdog (IWDG) start-up hung. The safety task waited for the watchdog's
    prescaler/reload update flags before starting the watchdog, but the watchdog's own clock (LSI)
    only runs once the watchdog is started, so the wait never ended. That task has the highest
    priority, so it starved the communication and logger tasks and the unit never answered PING.
    The start key is now written first and the wait is limited to 50 ms.
    Confirmed on the bench by the user: the unit starts and answers.
  The 2026-11-13 image (and anything built from it) has this hang and must not be used.

Earlier changes still in this build (PROJECT_LOG.md CL-77 to CL-86)
  - console on USART2 (PA2/PA3): the MCP2221A USB-UART on the Control Card (USB Type-C J8)
  - HV card N is on Control Card slot J<N> / enable EN<N>; HV card 1 shares J1/EN1 with the Matrix
    Card, so the Matrix segments are switched off the I2C bus before EN1 is raised for HV card 1.
    Up to 4 HV cards (BOARD_HV_COUNT, default 1)
  - BUS SCAN also probes each HV card's 8 relay expanders (HVn_HS1..4, HVn_LS1..4)
  - the minimum insulation resistance is configurable: LIMITS SET ins_min_mohm=<mohm>,
    100 kohm to 40 Mohm, default 10 Mohm; !INSUL and LIMITS GET carry 64-bit milliohms (FW-11)
  - the ID reply carries the firmware build stamp (FW-20)
