# 0 - Documents

All documents are in the standard document format, as editable Word files (`.docx`) with a PDF copy of each.

| # | Document | For |
|---|---|---|
| 1 | `1_System_Overview` | Everyone: what the HT_MK1 measures and how, the pass and fail conditions, pin support. |
| 2 | `2_User_Manual` | Operators: safety, connecting, loading a netlist, running Mode 1, Mode 2 and Auto scan, reports, troubleshooting. |
| 3 | `3_GUI_Functional_Description` | Operators and test engineers: every screen, section, button, dialog and message of the GUI, and the netlist file format. |
| 4 | `4_Flashing_Procedure` | Whoever programs the firmware onto a Control Card. |
| 5 | `5_Functional_Test_Procedure` | Acceptance testing of a built unit: test cases TC-01 to TC-08 with result tables to fill in. |
| 6 | `6_Code_Walkthrough` | Engineers maintaining the firmware or GUI: architecture, serial protocol, known limitations. |

Document numbers (shown in each page header): HT_MK1_OVW, HT_MK1_UM, HT_MK1_GUI, HT_MK1_FLASH, HT_MK1_FTP, HT_MK1_CWT.
The documents are issued by Atulya Core Tech (ACT) (page footer) to Infinity Integrations Pvt Ltd (distribution list). The approval names and the registered office address are left blank for you to fill in.
