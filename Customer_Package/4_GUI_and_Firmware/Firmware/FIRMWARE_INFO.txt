Changes in this build (since the 2026-10-23 image, see PROJECT_LOG.md CL-77 to CL-86)
  - console moved from LPUART1 to USART2 (PA2/PA3): the MCP2221A USB-UART on the Control Card
    ("USB to UART" sheet, USB Type-C J8); a Nucleo's ST-LINK VCP uses the same pins
  - HV card N is on Control Card slot J<N> / enable EN<N> (HW-15); HV card 1 shares J1/EN1 with
    the Matrix Card, so the Matrix segments are switched off the I2C bus before EN1 is raised
    for HV card 1. Up to 4 HV cards (BOARD_HV_COUNT, default 1)
  - BUS SCAN also probes each HV card's 8 relay expanders (HVn_HS1..4, HVn_LS1..4)
  - the minimum insulation resistance is configurable: LIMITS SET ins_min_mohm=<mohm>,
    100 kohm to 40 Mohm, default 10 Mohm; !INSUL and LIMITS GET carry 64-bit milliohms (FW-11)
  - the ID reply carries the firmware build stamp (FW-20)

Flashing
  Follow 0_Documents/4_Flashing_Procedure.pdf, then run its PING / PONG check before testing.
  Afterwards the GUI should connect and show "fw 0.1.0" in the status bar.
  The console is now the USB Type-C connector (J8); it appears as "USB Serial Device".

Not yet verified on hardware
  This image has been compiled and its pure logic unit-tested on a PC (124 checks), but not
  exercised on a unit. First power-up checks and the shared-EN1 / insulation-limit tests are in
  Doc/hardware_test_plan_2026-11-13.md (PROJECT_LOG.md BU-16, BU-17). Do not arm HV before BU-17
  passes. There is also no hardware interlock signal.
